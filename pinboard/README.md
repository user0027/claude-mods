# 핀보드 mod

작업 중에 남길 메모를 입력창 위에 고정한다. Claude Code 의 Mods 기능으로 만든 플러그인이다.

유튜브 Solostack 채널의 쇼츠(`8uO0CoaPDBM`)에서 소개한 핀보드를 보고 만들었다.

여기에는 직접 적은 메모만 들어간다. AI 가 물었는데 답하지 않고 넘어간 질문은
[`noti`](../noti/README.md) mod 가 따로 띠에 올린다.

## 동작

입력창 위 띠에 메모가 한 줄씩 나온다. 머리 줄은 따로 두지 않는다.

```
  ⎿  📌 : ★ 배포 전에 .env 키 확인
  ⎿  📌 : 렌더 끝나면 올리기
```

- 줄마다 알림 띠와 같은 `⎿` 가 흐리게 붙고, 한 줄씩 따로 읽히도록 모든 줄에 `📌` 가 붙는다.
  두 띠 모두 두 칸 들여 써서 왼쪽이 맞는다.
- **메모**는 `/pin` 으로 직접 적은 것이다. 앞에 `!` 를 붙이면 `★` 와 빨간색으로 나온다.
  9개까지 쌓이고, 꽉 찬 뒤에 새로 꽂으면 끝낸 메모부터, 없으면 가장 오래된 메모부터
  밀려난다. 번호는 쌓인 순서대로 매겨진다.
- 띠에는 글자만 나오고 번호와 버튼은 두지 않는다. 숫자키를 단 버튼은 번호를 꼭 같이 그리고,
  일반 화면에서는 띠에 마우스 클릭이 들어오지 않는다.
- 턴이 끝날 때마다 Haiku 가 이번 턴과 남은 메모를 같이 보고, 끝난 것 같은 메모가 있으면 체크하지
  않고 띠 아래에 `🤔 :` 한 줄로 묻는다. 메모와 헷갈리지 않게 알림 띠처럼 흐리게 그린다.
  알림 띠 mod 가 떠 있으면 이 줄을 따로 그리지 않고 알림 띠 한 줄에 맡긴다. 알림 띠는 이 물음을
  다른 알림보다 먼저 보여 준다. 묻는 문장은 그 턴 내용을 보고 Haiku 가 짓는다.
- 다음 입력이 됐다는 답이면 그 메모를 끝낸 것으로 바꾸고, 부족하다는 답이면 묻기를 거둔다. 상관없는
  말이면 그대로 둔다. AI 가 끝냈다고 본 것이 말없이 사라지지 않게 하려는 것이다.
- 띠에는 아직 끝내지 않은 메모만 나온다. 끝낸 메모는 `/pins` 화면에서 본다.
- 끝낸 것으로 표시하려면 `/pin 번호` 를 치거나 `/pins` 화면에서 체크한다. 끝낸 메모는
  흐려진다. 지우기는 `/unpin 번호` 나 `/pins` 화면에서 한다. 번호는 `/pins` 화면에 나온다.
- 끝낸 메모의 취소선은 핀보드 화면(`/pins`)에만 그린다. 띠에 그으면 한글이 깨져 보인다.
- 저장은 세션이 처음 뜬 작업 디렉터리별로 한다. 셸이 하위 폴더로 옮겨 가도 키가 바뀌지
  않는다. 같은 폴더에서 세션을 다시 띄우면 전에 쌓인 것이 그대로 나온다.
- 하위 폴더에서 연 세션은 핀이 있는 가장 가까운 위쪽 폴더의 판을 불러온다. 기억해 둔 판이
  비어 있으면 세션을 다시 불러올 때 위쪽 폴더를 다시 찾는다.

## 명령

| 명령 | 하는 일 |
|---|---|
| `/pin 메모` | 메모를 입력창 위에 고정한다. `/pin !배포 확인` 처럼 적으면 중요 표시가 된다. |
| `/pin 2` | 두 번째 메모를 끝낸 것으로 표시한다. `/pin done 2` 도 받는다. |
| `/pin edit 2 새 문구` | 2번 메모의 문구를 바꾼다. 앞에 `!` 를 붙이면 중요 표시가 된다. 끝냈는지는 그대로 둔다. |
| `/pin` | 핀보드 화면을 연다. |
| `/pins` | 핀보드 화면을 연다. 입력칸에서 추가하고 `[ ]` 로 체크, `x` 로 삭제한다. |
| `/unpin 2` | 2번을 지운다. 번호는 띠에 보이는 순서대로 세고, 끝낸 메모는 그 뒤에 이어 센다. `/pins` 화면도 같은 번호다. |
| `/unpin done` | 끝낸 것을 한 번에 지운다. |
| `/unpin all` | 끝낸 것과 남은 것을 모두 지운다. |

## 설치

터미널에서 연 Claude Code 입력창에 친다.

```
/plugin install pinboard --marketplace user0027/claude-mods
```

마켓플레이스를 추가할지 물으면 `y`, 범위는 Enter 로 사용자 범위를 고른다. 설치하면 그 세션부터 바로 켜진다.
Claude Code 2.1.287 이상이 필요하다.

## 저장 형태

`$.store` 의 `pins:<작업 디렉터리>` 키에 `{ memos }` 로 넣는다. 세션이 처음 정한
키는 `start:<세션 id>` 에 기억해 두고 세션이 끝나면 지운다.

## 파일

```
pinboard/
├── .claude-plugin/plugin.json   플러그인 manifest
├── hooks/hooks.json             hooks 모듈 경로
└── hooks/register.js            저장·띠·화면·명령
```
