# 📌 pinboard

작업하다 잊으면 안 되는 메모를 Claude Code 입력창 바로 위에 붙여 둔다.

```
  ⎿  📌 : ★ 배포 전에 .env 키 확인
  ⎿  📌 : 렌더 끝나면 올리기
```

- `/pin 메모` 한 줄이면 입력창 위에 고정된다. 앞에 `!` 를 붙이면 중요 메모로 빨갛게 나온다.
- 턴이 끝날 때마다 AI 가 끝난 것 같은 메모를 찾아 `🤔` 로 물어본다. 말없이 지우지 않는다.
- 메모는 폴더별로 저장된다. 같은 폴더에서 세션을 다시 열면 그대로 남아 있다.

## 설치

터미널에서 연 Claude Code 입력창에 친다. Claude Code 2.1.287 이상이 필요하다.

```
/plugin install pinboard --marketplace user0027/claude-mods
```

## 명령

| 명령 | 하는 일 |
|---|---|
| `/pin 메모` | 메모를 고정한다. `/pin !메모` 는 중요 표시 |
| `/pin 2` | 2번 메모를 끝낸 것으로 표시한다 |
| `/pin edit 2 새 문구` | 2번 메모의 문구를 바꾼다 |
| `/pins` | 핀보드 화면을 연다. 추가·체크·삭제를 한 화면에서 한다 |
| `/unpin 2` | 2번을 지운다. `/unpin done` 은 끝낸 것만, `/unpin all` 은 전부 |

[noti](../noti/README.md) 와 같이 쓰면 답하지 않고 넘어간 AI 질문도 같은 자리에 올라온다.
